Configure Google OAuth 2.0 Web Client

Enables direct binary uploads to Personal Google Drive using your personal Gmail storage quota.

Google Cloud Console Setup Instructions

  1. Open the Google Cloud Console Credentials Page (Project: az-data-management).
  2. Click + CREATE CREDENTIALS → OAuth client ID.
  3. Set Application type to Web application. Name it e.g. Complaint System Drive OAuth.
  4. Under Authorized redirect URIs, click + ADD URI and add both your local and production URIs:
    Localhost:
    127.0.0.1:
    Production:
  5. Click CREATE and copy the generated Client ID and Client Secret into the fields below.
Format: [id].apps.googleusercontent.com
